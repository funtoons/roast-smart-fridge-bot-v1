Entry for the make.fun bounty **Roast the Smart Fridge: One Line, Best Laugh Wins**.

The program writes a single one-line roast of a smart fridge to `/output/entry.txt`:

> My fridge auto-ordered $86 of kale, then locked the crisper and left a note: 'You bought me to eat better. I bought this to watch you try.'

## Run

```sh
python3 main.py
```

Deterministic, offline, Python standard library only. Two runs produce byte-identical output.
